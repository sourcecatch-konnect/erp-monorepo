# My daily work: booking / operations clerk

> Last checked: 2026-10-09 · One page. Details are in the chapters linked below.

## Every day

| # | Task | Where | Guide |
|---|---|---|---|
| 1 | Enter new customer **orders** | Operations → Orders → Create New Order | [Orders and LR §1](../03-orders-and-lr.md) |
| 2 | Ask the manager to **approve** them | (manager: open order → Approve) | §2 |
| 3 | For each truck, make the **LR group + LRs** | Order → Create LR (or Lorry Receipts → Create LR) | §3 |
| 4 | Link the truck: **trip** (own) or **transporter + freight** (market) | In the LR form | §3 |
| 5 | Add **invoice + e-way bill** to each LR, then **Finalise** | LR group → Finalise LR | §4 |
| 6 | **Print** the LRs for the driver | LR → Print | §5 |
| 7 | When goods reach the customer: **Mark delivered** | Operations → Deliveries | *(Delivery chapter)* |

## Check before you finish the day

- [ ] No order left in **Pending approval** without a reason
- [ ] Every truck that left has a **finalised** LR group
- [ ] Market trucks have the right **freight and advance**
- [ ] Deliveries reported by drivers are **marked delivered**

## If something goes wrong

| Problem | Do this |
|---|---|
| No freight on the order | Ask the admin to add the Rate Matrix row |
| Truck/driver blocked | Insurance or licence expired: tell the manager |
| Wrong LR after finalising | Don't make a new one. Tell the manager/admin |
